10. AI Tools

Di bawah thread sediakan:

Generate AI Reply
Summarize Thread
Translate
Detect Intent
Extract Info
Sentiment

Generate AI Reply

Generate draft berdasarkan seluruh thread aktif.

AI tidak boleh otomatis berjalan ketika GHL sync.

Hanya ketika agent menekan button.

Summarize Thread

Ringkas thread dan tampilkan poin penting sebagai informasi internal.

Jangan otomatis mengirim hasil ke customer.

Translate

Sediakan pilihan bahasa jika backend sudah mendukung.

Translation tidak boleh mengubah message asli secara permanen.

Detect Intent

Deteksi intent seperti:

Refund Request

Purchase

Technical Issue

Account Access

Cancellation

General Question

Gunakan hasil dari AI/backend yang sudah ada jika tersedia.

Extract Info

Ekstrak:

Customer Name

Order ID

Product

Problem

Requested Action

Important Dates

Tampilkan terstruktur.

Sentiment

Minimal:

Positive

Neutral

Negative

Jika tersedia, tampilkan confidence/score.
