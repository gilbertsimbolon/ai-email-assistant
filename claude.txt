# AI Workflow

Ini sangat penting.

AI **TIDAK BOLEH** berjalan otomatis.

Flow yang saya inginkan:

```
Email Masuk

↓

Sync Gmail

↓

Masuk Database

↓

Muncul di Inbox

↓

Agent Membaca

↓

Klik

✨ Generate AI Reply

↓

AI Membuat Draft

↓

Draft muncul di Textarea

↓

Agent Edit

↓

Klik Send

↓

Email dikirim melalui Gmail API
```

AI tidak boleh berjalan ketika:

- Inbox dibuka
- Gmail melakukan polling
- Gmail melakukan sync
- Refresh halaman

AI hanya berjalan ketika user menekan tombol:

Generate AI Reply

Hal ini untuk menghemat penggunaan token AI.
