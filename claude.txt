Saya ingin kamu menyempurnakan SIDEBAR pada aplikasi Laravel saya.

Gunakan kode sidebar yang sudah ada sebagai baseline. Jangan langsung mengubah kode sebelum memahami struktur layout utama, JavaScript Sneat, CSS/theme, dan behavior sidebar yang sekarang.

==================================================
GOAL UTAMA
==================================================

Saya menggunakan template Sneat dan ingin sidebar menjadi lebih polished, modern, responsive, dan nyaman digunakan baik di desktop maupun mobile.

Sidebar harus memiliki behavior seperti dashboard/admin panel modern.

Target behavior:

1. DESKTOP
   - Sidebar tampil normal secara default.
   - Tersedia tombol toggle/collapse di bagian header sidebar.
   - Ketika tombol diklik:
     - sidebar menjadi collapsed/narrow
     - icon menu tetap terlihat
     - label menu disembunyikan
     - content utama otomatis melebar
   - Ketika diklik lagi:
     - sidebar kembali expanded
     - label menu muncul kembali
   - Icon tombol toggle harus berubah:
     - expanded → chevron-left
     - collapsed → chevron-right

2. MOBILE
   - Jangan merusak behavior mobile/offcanvas bawaan Sneat.
   - Sidebar tetap bisa dibuka/tutup menggunakan behavior responsive bawaan Sneat.
   - Jangan memaksakan desktop collapsed behavior ke mobile.
   - Pastikan tombol close mobile tetap berfungsi.

3. DESKTOP DAN MOBILE HARUS DIPISAH BEHAVIOR-NYA
   - Desktop menggunakan collapse.
   - Mobile menggunakan offcanvas/mobile menu behavior.
   - Jangan membuat satu JavaScript yang menyebabkan konflik antara kedua behavior tersebut.

==================================================
IMPORTANT CURRENT PROBLEM
==================================================

Saat ini tombol sidebar hanya terlihat pada mobile karena icon menggunakan:

d-xl-none

Saya ingin tombol toggle juga tersedia di desktop.

Namun ketika saya menghapus d-xl-none, tombol memang muncul di desktop tetapi ketika diklik sidebar tidak collapse.

Jadi jangan hanya menghapus d-xl-none.

Cari tahu bagaimana Sneat layout dan JavaScript bawaan bekerja terlebih dahulu.

==================================================
REQUIREMENTS
==================================================

### 1. Desktop Sidebar Toggle

Buat tombol toggle yang benar-benar bekerja di desktop.

Behavior:

Expanded:

[Logo] AI Email Assistant              <

Collapsed:

[Logo]                                  >

Ketika collapsed:

- Sidebar menjadi sempit
- Hanya icon menu yang terlihat
- Text menu disembunyikan
- Menu header seperti "AI Center", "Reports", "Administration" tidak mengganggu layout
- Badge/menu counter ditangani dengan baik
- Profile information di bagian bawah menyesuaikan
- Logout button menyesuaikan
- Main content melebar otomatis

Jangan membuat sidebar disappear total.

### 2. Mobile

Pertahankan behavior mobile Sneat.

Mobile harus tetap:

- bisa open
- bisa close
- bisa menggunakan overlay/backdrop jika Sneat menggunakannya
- tidak menyebabkan horizontal overflow
- tidak menyebabkan body bisa scroll aneh

### 3. Persistence

Jika memungkinkan, simpan state desktop sidebar menggunakan localStorage:

sidebarCollapsed = true / false

Sehingga:

- user collapse sidebar
- refresh halaman
- sidebar tetap collapsed

Tetapi jangan menyimpan state mobile sebagai desktop collapsed state.

### 4. Responsive Breakpoint

Gunakan breakpoint Sneat/Bootstrap yang sudah digunakan project.

Jangan membuat breakpoint random jika Sneat sudah memiliki breakpoint yang sesuai.

Desktop behavior hanya aktif pada breakpoint desktop.

Mobile tetap mengikuti behavior responsive Sneat.

### 5. Icon

Gunakan Boxicons yang sudah tersedia.

Expanded:

bx-chevron-left

Collapsed:

bx-chevron-right

Jangan menambahkan library baru.

### 6. Tooltip ketika collapsed

Saat sidebar collapsed di desktop:

- menu icon harus tetap bisa dipahami
- tampilkan tooltip berisi nama menu ketika hover

Contoh:

🏠 → Dashboard
💬 → Conversations
🧠 → AI Center

Gunakan Bootstrap tooltip atau mekanisme tooltip yang sudah tersedia di project.

Jangan membuat library tooltip baru.

### 7. Nested Menu

Perhatikan menu seperti:

AI Center
Reports
Settings
Integrations

Ketika sidebar collapsed:

- icon parent tetap terlihat
- submenu tidak boleh menyebabkan layout rusak
- submenu harus tetap bekerja ketika sidebar expanded
- jangan menghilangkan functionality menu-toggle
- active state tetap benar

### 8. Active State

Jangan mengubah logic Laravel seperti:

request()->routeIs(...)
@can(...)
@canany(...)

Semua permission dan active state yang sudah ada harus tetap bekerja.

Jangan mengubah route.

Jangan mengubah authorization logic.

### 9. Bottom User Section

Bagian:

Profile
User name
Email
Logout

harus tetap terlihat bagus ketika:

EXPANDED:

[Avatar] Gilbert Simbolon
         email@example.com
[ Logout / Keluar ]

COLLAPSED:

[Avatar]
[Logout icon]

Jika text tidak muat ketika collapsed, sembunyikan text tetapi jangan menghilangkan functionality.

### 10. Logo

Ketika expanded:

[logo] AI Email Assistant

Ketika collapsed:

[logo]

Pastikan logo tetap terlihat dan tidak rusak.
