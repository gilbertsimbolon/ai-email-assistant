STEP 7 — JIKA DATA TIDAK ADA
==================================================

INI SANGAT PENTING.

Jika setelah API audit ternyata Contact API memang tidak memiliki data transaksi, JANGAN hanya membuat field tetap "-".

Cari tahu:

1. Apakah data pembelian memang disimpan di GHL?
2. Jika iya, endpoint mana yang menyimpannya?
3. Jika tidak, apakah data tersebut berasal dari sistem eksternal/integrasi Content360?
4. Apakah GHL hanya menerima customer/contact + conversation tetapi transaksi tersimpan di platform lain?
5. Apakah tag "purchase - c360 lifetime" hanya menunjukkan status pembelian tanpa menyimpan detail transaksi?

Jika tidak ditemukan, jelaskan dengan bukti dari response API.

==================================================
STEP 8 — PRIVATE INTEGRATION
==================================================

Karena Private Integration BARU sudah dibuat dengan SEMUA SCOPE:

- jangan meminta saya membuat integration baru lagi

Tambahkan debug untuk memastikan integration yang aktif memang integration baru.
