# Prompt: Redesign Tampilan Inbox Laravel (GHL Integration)

## 📌 Deskripsi Tugas
Tolong perbarui dan faktorkan ulang (*refactor*) tampilan interface **Inbox/Conversations** pada aplikasi Laravel kami.

Ubah tampilan aplikasi dari **Gambar 1 (Kondisi Saat Ini)** agar memiliki tata letak (*layout*), hierarki visual, dan gaya desain yang presisi seperti pada **Gambar 2 (Referensi Target)**.

> **Catatan Penting:**
> - **JANGAN** mengubah logika backend, nama rute (*routes*), variabel Blade, atau integrasi GoHighLevel (GHL) yang sudah berjalan.
> - Tugas ini berfokus pada **UI/UX Refactoring** (Blade Views, Tailwind CSS / Bootstrap, & komponen visual).
> - Seluruh data nyata yang tampil di Gambar 1 (seperti pesan dari "Content360", nama "Rhonda", filter, dll.) harus tetap dirender dengan benar menggunakan variabel Laravel yang ada.

---

## 🎯 Detail Perubahan Visual (Berdasarkan Gambar Referensi 2)

### 1. Structure & Layout (3-Column Layout)
Ubah tata letak utama menjadi **3 Kolom Responsif** (sebelumnya hanya 2 kolom di Gambar 1):
- **Kolom 1 (Kiri):** Navigation / Conversation List Panel.
- **Kolom 2 (Tengah):** Main Thread / Conversation View & Chat Input.
- **Kolom 3 (Kanan):** Contact Details & Actions Side-Panel (Buat komponen baru/tampilkan panel ini jika sebelumnya tersembunyi).

---

### 2. Panel Kiri: Conversation List Header & Filter Group
- **Filter Bar:**
  - Ubah tombol filter berbentuk pill/teks biasa menjadi **Icon Group Compact** di bagian atas (menggunakan icon: *Unread*, *All*, *Recent*, *Starred*).
  - Tambahkan **Badge Count** berwarna biru menempel di atas icon *Unread* (misal: `1.4K` atau variabel `$unreadCount`).
- **Item List Percakapan:**
  - Tambahkan *checkbox* "Select All" di atas daftar.
  - Setiap card percakapan disederhanakan:
    - **Avatar bulat** dengan inisial nama (misal: "TS", "AS", "RH").
    - **Nama Kontak** (font tebal).
    - **Pratinjau Pesan Terakhir** (*truncated text*).
    - **Timestamp/Tanggal** (misal: "Aug 3") di pojok kanan atas item.
    - **Badge Unread Message** berbentuk lingkaran biru berisi angka di kanan bawah item.
    - Icon Bintang (*Star*) untuk penanda percakapan favorit.

---

### 3. Panel Tengah: Thread View & Chat Input
- **Header Chat:**
  - Tampilkan avatar kontak, nama kontak aktif, serta tombol-tombol *quick action* di pojok kanan atas (Icon Telepon, Star, Email, Delete, dan Collapse).
- **Bubble Message:**
  - Hapus background box ungu tebal dari Gambar 1!
  - Ubah gaya pesan menjadi **Clean Boxed Cards/Bubbles** dengan background abu-abu muda/putih halus.
  - Tampilkan Avatar Pengirim (misal "DP" untuk Dom Ricci) pada setiap blok pesan.
  - Tampilkan nama pengirim, email tujuan/penerima (`To: ...`), serta timestamp waktu (misal: `05:12 AM`).
  - Tambahkan pemisah tanggal di tengah area chat (*Date Divider*), contoh: `Jul 21`, `Jul 22`.
- **Input Area (Bottom Chat Bar):**
  - Buat input area melayang/bersatu di bawah thread dengan tombol pengirim icon pesawat kertas (*Send Button*) berwarna biru di pojok kanan.
  - Sertakan dropdown pilihan *channel* (misal: Email/SMS) di sebelah kiri input text.

---

### 4. Panel Kanan: Contact Details (Sidebar Kolom Ke-3)
Buat/Sesuaikan komponen sidebar kanan untuk menampilkan detail kontak secara komprehensif:
- **Header Details:** Judul "Contact Details" dengan tombol *close* (X) dan *pop-out icon*.
- **Profile Summary:** Avatar inisial besar, Nama Kontak, dan *Owner/Followers* dropdown field.
- **Tags Section:** Tampilkan tag kontak dalam bentuk pill/badge (misal: `purchase - c360 lifetime`).
- **Tab Navigation:** Sub-nav mini (`All fields`, `DND`, `Actions`).
- **Search Field:** Input pencarian internal fields (`Search fields and folders`).
- **Collapsible Field Accordion:**
  - Accordion **Contact** berisi informasi detail yang diambil dari DTO/Database kontak:
    - *First Name*
    - *Last Name*
    - *Email* (dengan icon aksi cepat)
    - *Phone* (dengan *country code selector*)
    - *Date of Birth*
