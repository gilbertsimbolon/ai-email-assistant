# REDESIGN UI/UX – FULL SCREEN MODERN AI EMAIL ASSISTANT

## OBJECTIVE

Redesign the entire UI of the AI Email Assistant to look like a modern SaaS application.

The current interface wastes a lot of screen space. There are large empty areas, inconsistent spacing, and fixed-width containers that make the application look unfinished.

The goal is to transform the application into a full-screen, professional dashboard similar to:

- Google Workspace (Gmail)
- Microsoft Outlook
- Linear
- Notion
- Slack
- Zendesk
- Intercom
- HubSpot

Do **NOT** simply change colors.
Redesign the layout and component structure.

---

# GENERAL RULES

- Use Bootstrap 5 only.
- Continue using the Sneat Bootstrap Template.
- Reuse existing Bootstrap utilities whenever possible.
- Do not create unnecessary custom CSS.
- Responsive for Desktop, Tablet, and Mobile.
- Clean spacing.
- Modern shadows.
- Rounded corners consistent with Sneat.
- No unused whitespace.
- Every page should maximize available screen space.

---

# GLOBAL LAYOUT

The application should always occupy the entire browser viewport.

Layout:

```
-------------------------------------------------------------
| Sidebar | Top Navigation                                  |
|         |-------------------------------------------------|
|         |                                                 |
|         |                 Content Area                    |
|         |                                                 |
|         |                                                 |
-------------------------------------------------------------
```

Requirements:

- Sidebar full height (100vh)
- Topbar full width
- Content uses all remaining space
- No centered container with huge margins
- Remove unnecessary max-width wrappers
- Use flexbox layout

Example:

```
display:flex

Sidebar
    width:280px

Content
    flex:1
    min-width:0
```
