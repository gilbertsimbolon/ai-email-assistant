Kamu adalah seorang Senior Software Architect, Senior Laravel Developer, dan Software Refactoring Engineer.

Saya ingin melakukan perubahan arsitektur secara total pada project ini.

## Tujuan

Saya memutuskan untuk TIDAK LAGI menggunakan GoHighLevel (GHL) sebagai sumber data utama.

Mulai sekarang sistem ini akan menggunakan Gmail API sebagai satu-satunya sumber data email.

Anggap seluruh implementasi GoHighLevel adalah arsitektur lama yang harus dihapus.

==================================================
TUGAS UTAMA
==================================================

Lakukan audit menyeluruh terhadap seluruh project.

Kemudian lakukan refactor besar-besaran sehingga project berubah menjadi Gmail API Architecture.

Jangan mempertahankan kode lama hanya karena mungkin akan dipakai nanti.

Jika memang sudah tidak digunakan, hapus.

==================================================

- Webhook GHL
- Job GHL
- Event GHL
- Listener GHL
- Middleware GHL

- Model khusus GHL
- Helper GHL
- DTO GHL
- Resource GHL
- Cache GHL
- Scheduler GHL
- Queue GHL
- Test GHL
- Environment Variable GHL
- Documentation GHL

Cari seluruh referensi GHL di seluruh project.

Jika sudah tidak dipakai, hapus.
